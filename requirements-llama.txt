# Dependencias OPCIONALES para el provider local llama_cpp (Fase 3).

# NO es parte de requirements.txt: se instala solo cuando se quiere usar el
# modelo embebido via llama.cpp sin Ollama/OpenAI. La base del binario no crece

#   pip install -r requirements-llama.txt

# IMPORTANTE: llama-cpp-python NO publica wheels en PyPI (solo el sdist, que
# requiere toolchain C/C++ tipo MSVC/nmake y compila todo desde cero). Las
# wheels precompiladas de CPU estan en el indice oficial de abetlen
# (https://abetlen.github.io/llama-cpp-python/whl/cpu) con tag universal `py3`,
# compatibles con cualquier Python 3.x (incluido 3.14):
#
#   --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
#
# Para builds con aceleracion (CUDA/Metal/Vulkan) consulta la documentacion del
# proyecto y usa el indice correspondiente (p.ej. pip install --index-url=...).
